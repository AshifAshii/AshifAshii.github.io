# Ashif Ahamed - Portfolio

A responsive portfolio built with **React**, **Vite**, and **Material-UI (MUI)**.

## Features

- **Material-UI** design system with dark theme
- **Responsive layout** — mobile drawer navigation, adaptive grids, fluid typography
- **Sections**: About, Experience, Projects, Technologies, Education, Contact
- **Contact form** with validation and API integration

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
```

Output is in the `dist/` folder. Static assets are served from `public/img/`.

## Deployment (GitHub Pages)

1. Build: `npm run build`
2. Deploy the contents of `dist/` to your GitHub Pages branch or root
